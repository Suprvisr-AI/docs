# Changelog

A running log of new features, improvements, and fixes in Cumulus.

---

## March 2026

### Web Search
Search the web for real-time information directly from chat. Use the `/websearch` slash command or just ask a question that needs current data. Results include inline citation chips linking to original sources. Queries are automatically sanitized to strip personal information. Admins can enable or disable web search from Settings. → [Learn more](/features/web-search)

### Slash Commands
Type `/` in the chat input to access quick commands: `/websearch` for web search, `/image` for image generation, and `/data` for document search. Navigate with arrow keys or Tab, select with Enter. Commands appear as a blue prefix in the input field. → [Learn more](/features/slash-commands)

### Image Generation Admin Toggle
Admins can now enable or disable image generation for their organization from Settings. When disabled, the `/image` command is hidden and the AI will not generate images. → [Learn more](/features/image-generation)

### Tool Call Timeline
A new expandable timeline in chat shows each tool the AI uses in real time — with step-by-step progress, icons, and timing. Consecutive same-tool calls are deduplicated for a cleaner view.

### Mobile Responsiveness
The app is now fully usable on mobile devices. Chat input stays visible (no more hiding behind the browser chrome), the sidebar opens as an overlay drawer with a hamburger menu, dashboard and settings navigation use horizontal tab bars, and the artifact panel opens as a full-screen overlay. Tool UI buttons are now touch-friendly on all screens.

### Image Generation
Ask the AI to generate images directly in chat. Images render inline with a lightbox view and download button. Each user gets a weekly generation quota — usage is tracked per image. → [Learn more](/features/image-generation)

### Knowledge Base
Upload documents (PDF, DOCX, XLSX, TXT, MD) to your organization's knowledge base from Settings. The AI automatically searches indexed documents when answering questions. Includes file status tracking, chunk counts, and search/delete management. → [Learn more](/features/knowledge-base)

### AI Personality
Admins can now shape the AI's tone and perspective for their organization. Configure two personality traits, a brand worldview, value proposition, and custom instructions — with a live preview that updates as you type. → [Learn more](/features/ai-personality)

### Workspaces
Project folders with shared AI context are now live. Each workspace has five tabs: Overview, Chats, Sources (file uploads with status tracking), Team (role-based access), and Memory (persistent project context). Create workspaces from the sidebar, upload documents, invite collaborators, and compare files. → [Learn more](/features/workspaces)

### Reasoning Levels
Control how deeply the AI thinks before responding. Four levels available via the settings panel in chat: Minimal (fast), Low (some reasoning), Medium (balanced), and High (deep analysis). → [Learn more](/features/reasoning-verbosity)

### Dictate
Voice-to-text input is now live. Click the mic icon in the chat input to start dictating — your words appear in the text field as you speak. Edit before sending, click again to stop. → [Learn more](/features/dictate)

### Citations
AI responses that draw from your internal data now include citation chips showing exactly which document and section was used. Click any citation to expand and read the source excerpt. → [Learn more](/features/citations)

### Dashboards
User and admin dashboards showing usage frequency, estimated time saved, common topics, and adoption rates. Admins get an organization-wide view with per-user breakdowns. → [Learn more](/features/dashboards)

### Self-Destructing Chats
Admin-controlled private chat mode is now available. Conversations are not saved to history unless the user chooses to save them. Enable from Settings → Organization. → [Learn more](/features/self-destructing-chats)

### Member Invitations
Admins can invite team members by email. Invitees receive a branded email and land on an invitation page showing the org name and who invited them. New users go through onboarding automatically after accepting. Pending invitations can be resent or revoked. → [Learn more](/features/member-invitations)

### Google Drive Per-User Permissions & Personal Drives
Google Drive search results are filtered by each user's actual Google Drive permissions. Admins can enable a "Personal Drives" toggle for team members. Sync now uses webhooks for faster content updates. → [Learn more](/features/google-drive)

### SharePoint Sync Progress
SharePoint connections now show real-time sync progress with file-level detail — including pending, processing, indexed, and failed counts. Non-admin members see connection status without exposing configuration details. → [Learn more](/features/sharepoint)

### AI Memory
Import your AI context from ChatGPT, Claude, Gemini, or any other assistant. Memories are organized into three pools (identity, instructions, knowledge) with smart retrieval. Includes admin controls per org and per workspace. → [Learn more](/features/user-memory)

### Chat UI Improvements
Inline mid-stream thinking indicators, full tool label coverage for all backend tools, and provisional chat sessions that update the sidebar instantly on send.

### Super Admin Dashboard

- Added `/super-admin` route gated to `@suprvisr.ai` email addresses
- **Overview**: 9 KPI cards — total tenants, users, DAU, messages today, active subscriptions with MRR, SharePoint files, uploads, conversations, and total storage
- **Trends**: 4 time-series charts (DAU, messages/day, new tenants/week, SharePoint files synced) with 7/30/60/90-day time range selector
- **Tenants table**: Sortable view of all orgs with per-tenant 30-day stats, subscription status, and MRR
- **Re-engagement panel**: Lists dormant tenants and users (inactive 7+ days or never used) with one-click "Copy email" for outreach
- **Mailing panel**: Listmonk subscriber count, list breakdown, and recent campaign stats (configure via env vars)

## February 2026

### Dice Prompt Feature

- Added a **dice icon** to the empty chat state
- Clicking the dice inserts a role-specific example prompt into the input field
- Prompts curated per role: Developer, Designer/Marketer, PM, Sales, Admin, and Other
- Prompts stored in the database — updated without code deploys
- Greeting in empty state now uses your preferred name from onboarding

- "Redo Onboarding" button added to Settings → Personalization
